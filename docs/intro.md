# Ice, Ocean, and Sea Level Analysis

Welcome! This is a community resource for analyzing MOM6, SIS2, and MOM6_IS model output.

These pages are under active development, so take them with caution for the time being.

While there are many existing resources for MOM6 (please see existing links), there are fewer for the cryosphere model components. We aim to bridge this gap.

## What's here?
- Reusable Python functions for ocean and cryosphere diagnostics
- Tutorial notebooks organized by topic
- Links to existing community resources
